# Number Guessing Game

A simple Number Guessing Game built using HTML, CSS, JavaScript, and Bootstrap. The game allows the user to enter a number between **1 and 100** and checks whether the guess is correct.

## Live Demo

https://kathrinenancy.github.io/number-guessing-game/

---

## Features

- Guess a number between 1 and 100
- Input field for entering the guess
- Check button to verify the entered number
- Displays the game result
- Simple and responsive interface

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 4.5

## How It Works

1. Enter a number between **1 and 100**.
2. Click the **Check** button.
3. The game compares your input with the generated number.
4. The result is displayed on the screen.
